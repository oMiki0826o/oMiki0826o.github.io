# V5 細節系統設計

## 目標

在不改變 Miki 既有 V5 視覺語言的前提下，讓網站從靜態的個人頁面變成有節奏、可探索、但不打擾閱讀的個人網站。核心氣氛仍是淺藍、薄荷、微暖色與螢火蟲；不導入儀表板、霓虹、過度玻璃卡片或模板化的 portfolio 元件。

成功標準：手機與桌面皆自然、動畫可被停用、所有互動可用鍵盤操作、內容比動畫重要、ripmiki 仍保持完全獨立。

## 設計原則

1. **靜中有動。** 動畫只標示進入、離開、回應，不能持續搶注意力。
2. **先閱讀、再探索。** 首頁不增加大型功能區；彩蛋藏在既有內容與頁尾附近。
3. **可逆且可及。** `prefers-reduced-motion` 時關閉非必要運動；焦點與按壓狀態要清楚。
4. **不破壞資料架構。** 不新增後端、不改靜態輸出與三語內容模型。

## 範圍

### 1. 導覽

- 保持「左漢堡、中間 Miki、右語言／主題」的既定配置。
- 選單開啟時提供背景遮罩、滑入位移、目前頁識別、Escape 關閉與點擊遮罩關閉。
- 開啟後焦點維持在選單脈絡；切頁與切換語言後選單自然關閉。
- 導覽不改成參考圖的黑色樣式，仍使用主站的半透明淺藍薄荷表面。

### 2. 首頁節奏

- Intro、音樂、鎮樓圖與每一個 section 使用同一套淡入／微上移 reveal。
- 作品卡與筆記列增加細微 hover、focus、touch-active 回饋；不改卡片比例與現有配色。
- 鎮樓圖僅在游標可 hover 的裝置使用非常小的位移與光感，手機不做視差。
- Timeline 保留既有 scroll-driven 漸層淡入淡出；補一個非支援瀏覽器的 IntersectionObserver fallback。

### 3. 閱讀頁

- Notes 詳細頁新增頂端閱讀進度細線與固定但低調的「回到頂端」按鈕。
- 文章段落、標題與外連結補足可讀性、選取、hover 與鍵盤焦點狀態。
- 不把文章改成 Medium、Notion 或技術文件模板；不改公開文章內容的口吻。

### 4. 彩蛋

- 主站新增一個低頻、可被發現的螢火蟲互動：點擊背景的小光點會短暫聚亮後消散。
- 不記錄使用者資料、不出現提示文字、不影響連結與文字選取。
- ripmiki 的獻花互動保留原樣，不和主站共用樣式或行為。

### 5. 響應式與品質

- 在 320px 至桌面尺寸避免橫向捲動；抽屜選單、回頂按鈕與社群連結維持可點擊面積。
- 深／淺主題都維持文字與邊線對比，且選單、進度、reveal 使用 token，不硬編碼另一套色彩。
- 更新單元與 E2E：選單開關／Escape、文章路徑、動畫降級、手機無 overflow、彩蛋不遮擋內容。

## 元件與資料流

新增的 client-side 元件只限於：

- `SiteHeader`：抽屜的關閉條件、目前路徑狀態。
- `ScrollReveal`：觀察 `[data-reveal]` 元素；motion-reduce 時直接顯示。
- `ReadingProgress`：依文件高度繪製文章頂部細線。
- `BackToTop`：跨過可讀閾值後顯示，使用原生 smooth scroll。
- `FireflyField`：現有裝飾的擴充，僅對背景安全區回應，生成短生命的光點。

內容檔、語系鍵與 URL 規則不改。CSS 集中在 `app/globals.css` 的 token、base、interaction 與 motion 區段；ripmiki 規則保留在獨立區塊。

## 錯誤處理與降級

- JavaScript 未載入時，內容、連結、語言與主題仍可讀；選單的主導覽以可見 fallback 呈現或不會藏住路徑。
- `IntersectionObserver` 不存在時，不套用初始隱藏狀態。
- `animation-timeline` 不存在時，以 observer 顯示 Timeline，不留隱形內容。
- `prefers-reduced-motion` 時 reveal、視差、螢火蟲互動與回頂平滑捲動均降級。

## 驗證

最終一次完整執行：

1. `npm test`
2. `npm run build`
3. `npm run test:e2e`
4. 靜態輸出路徑與 `git diff --check`

E2E 覆蓋桌面與 320px 手機，包含三語首頁、導覽、深淺主題、Notes 詳細頁、ripmiki 與無水平溢出。
